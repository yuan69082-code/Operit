# 结构化报告与持久化

原工具只允许修改维度定义，新维度从基准开始，无法将初次体验与定义一起保存。

本步增加带本轮身份的状态报告。输入提供真实事件引用、助手归属和定义版本；报告可以更新任何已有维度，或在同一批次中创建完整定义并写入初次体验值。长期基准与当前体验分开。

协议使用 `operit_state_report` 标签包裹 JSON。JSON 包含 `frame_id`、`updates` 与 `create`；空数组表示本轮没有需要记录的变化。新增定义必须有类别和现有时间参数。报告中的当前值是主观评估，必须有解释和有效来源绑定。

提交在副本上验证整批数据，再使用原有原子存储保存。检查回合幂等、状态版本、定义版本、来源和数值范围；不将部分有效数据写成一次成功报告。被省略的维度继续保留。

文本消息与自主判断先记录事实，不再同时按关键词制造同一份主观变化。时间变化与明确客观事件的现有规则保留；语义报告写当前值，不把同一经历再累加一次。
