# 按状态浏览与变化定位

## 原状与意图

当前、事件、演化规则三个平铺入口将多个状态混排，单卡高度过大。新的入口围绕单个状态组织：在类别下看紧凑趋势，点入后查看该状态自己的事件和规则。

## 约定

- 当前入口提供驱力、情感、情绪、心理筛选；存量未分类状态保留明确入口。
- 小卡片以名称、当前数值和紧凑趋势为主，点击打开状态详情。
- 实际变化点可定位到时间、前后数值与可展示的事件原因。曲线不虚构波动，不跨越被隐私过滤的历史补线。
- 详情仅展示当前状态与作用域的数据，演化规则和版本历史默认折叠，展开后完整显示。
- 新时间规则尚未定义时显示原因和正在使用的原规则，不将旧参数猜成新条件。
- 名称变化后仍沿稳定 ID 浏览完整历史。

## 实现范围

`InternalStatePanel` 与按状态构造的趋势、事件视图，沿用 `InternalStateEngine.observation` 的隐私过滤。

## 验证计划

静态核对列表密度、类别切换、状态筛选、图上点选、事件与规则折叠、历史隐私断点。设备交互与布局仍需要实际安装验证。

紧凑列表、四类筛选、待分类区域、单状态详情、变化定位和规则折叠已实现。7 项时间线／图表纯测试已包含在本机 122 项通过结果内；完整 Compose 编译由 Android 发布构建验证。
