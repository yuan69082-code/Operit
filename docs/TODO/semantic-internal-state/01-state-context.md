# 输入选择与状态分类

原实现将所有活跃维度、最后八次变化和全部到期念头加入请求，待办与阅读来源在关联判断之前按数量截断。

本步将完整保留的数据与本轮上下文分开。以当前输入、对象、近期变化、未解决体验和主体自己的关注选择有界的详细资料，同时提供简短维度目录。选中与否不改变状态的存续，也不直接决定行动。

定义增加驱力、情感、情绪分类和可选对象。旧定义未分类时仍按原参数运行，原值、时间锚点、范围、历史及作用域保持。新定义必须明确时间规则，不新增预置维度或速度。

相关范围为 InternalStateEngine、InternalStateStore、CompanionContext、ConversationService 与 RuntimeContextSections。估算和界面预览不能记录真实唤醒、消耗轮换位置或修改权威数据。
