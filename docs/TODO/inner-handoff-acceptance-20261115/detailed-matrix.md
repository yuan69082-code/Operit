## 来源确认与边界

已从只读引擎仓库读到 `dynamic_mind.py`、`open_needs.py`、`open_affect.py` 和 `项目愿景与核心定位_园园原文.md`。本轮找不到指定名称的另外两份本地增补原文（尚未证明其内容不存在）；已按园园本轮完整明确的清单覆盖范围，不能冒称读过那两份文档。

这份矩阵严格区分「已装入机制」和「已有一次具体体验」，也区分「自动化测试」与「真实模型/真机/长期运行证据」。`InnerFoundations.kinds` 是安装好的 92 个**可承载类别**，不是 92 个已经体验过的内心事实。

原人格、关系、偏好、历史、未完成事项不清空。遗留数值仍可查，但已从新体系的正常数值写入口、原时间计算中退出；仅稳定 ID 与完整语义匹配的基础驱力自动承接数值，无法可靠归类者标记待语义承接，不能假装迁移。

## 整体运行链与现有事实

正常私聊输入／真实工具结果 → `InternalStateStore.prepare` → `InnerFoundations.material`、`InnerStructure.material`、`CategoryEvents.material`、`InnerInteractions.material` → `SubjectMaterialBudget.select`（统一上限）→ 模型生成正常回复、工具选择及可选末轮状态报告 → `InternalStateReports.apply` 在同一份主体文档验证后提交 → 后续真实轮次重新选择相关材料。

已复用的基础设施：`CompanionStore`、`InternalStateDocument`、`InnerRows`、`CategoryEvents` 归档、`InternalStateStore`、已有候选/采用版本、`ActionUnderstanding`、`SubjectRestDreams`、`AssistantWindowRouter`、工具与记忆检索。没有另建记忆库或第二主体权威。

ISR 错误经 `InternalStateReportDiagnostics` 细分结构和阶段路径，在 `InternalStateStore.noteReportFailure` 保存不包含人格原文的失败元数据，在下一次实际请求中可增量送达。合法报告同轮原子验证，失败不重跑已完成工具。截图 `ISR_FORMAT` 无原始失败日志，**不能反推真实字段根因**。

## 各类别共享的实际职责

分类目录由宿主初始化；心理**事情**由 `CategoryEvents.appraise` 按事件 ID、对象、来源、强度、重要性、当前注意与长期影响分别形成；重点 `focus` 每类3—6个位置，全部事件无此上限。持续人格、关系、偏好等采用 `InnerStructure` 的完整候选版本与跨真实轮次读取限制。联合以成员版本、关系、支持/牵制、当时解释记录；不会自动将数值互相加减，也不会重播同一事件。

当前**未全面完成**引擎原版对所有数值的自动耦合（例如身体模拟维度与各驱力、关系深度对愤怒自然曲线的影响）；当前实现偏向有来源的主体主动评价和下一轮材料影响。不能声称已完整迁移所有原始算法，也不能把这些不足归为仅剩界面优化。

## ISR、迁移、时间、性能与恢复的验证门槛

1. 旧数据：核对实际用户设备中的旧人格原文、关系、偏好、候选及历史条数、分配的助手 ID、多个聊天窗口与不同模型。仓库自动测试**不能**证明用户手机数据完整迁移。
2. 单一权威：检查旧 `definitions` 全部停用但原始版本与 `instances` 留存；冻结旧自动触发与 `updates/create/revise`；新驱力使用 `foundation`，具体体验用 `episodes`，稳定内容用 `inner`。未能可靠映射的旧条目必须保留 `pending_semantic_mapping`。
3. 同类别事情：用真实输入及同一助手不同窗口产生 A、B、C 的独立事件，A 的版本变化不可重写 B、C；来源唯一事实 ID 不重复计算，重点变动不删除历史。
4. 求生欲：明确升降、归零、变化对象关联、重启及时间后仍保持；旧已采用 `semantic_rule=survival` 必须有来源版本而非再次初始化为零。变化前后的对象数组和目标数组必须能追溯。
5. 候选：继承原人格、关系和偏好原文；新候选在后续真实轮次完整读取后才可采用；人格采用版本保持不可变；当前情绪变化不触发人格审批。
6. ISR：`InternalStateReportDiagnostics` 输出固定细分码、可归属字段路径和版本；失败事务不生效，既有状态、工具结果不重跑；下次送达安全精简失败说明。
7. 性能：统一预算和截断原文的 locator；长历史不能每轮全带；`material_budget` 中省略计数不代表数据删除。检查提示常量和模型工具定义长度，不能把预算以外的无关文本重复追加。
8. 实际行动：需要真模型/设备环境证明偏好、相互拉扯与成功或失败的技术回执真正影响后续取材、表达、探索或工具选择；测试夹具不能宣称覆盖这一步。
9. 梦醒：无需完整梦境剧情；独立保留梦记忆/感觉/想法/心情/打算/是否交流，注意梦境绝非现实事件证据。
10. 发布：PR 合并及新 APK 上传必须由验证后的发布流水线完成。CI 绿色不是设备端已安装；实际手机验证仍为未验证。

**当前结论**：已具备主体目录、事件归档、单事务、已采用内容保护、真实动作反馈的部分端到端基础，但全 92 项的自然运行效果、全部原库数值耦合、真实设备迁移和长期运行尚无全面证据。严格按要求应标为**部分实现／未验证**，不得标成「全部完成」。
