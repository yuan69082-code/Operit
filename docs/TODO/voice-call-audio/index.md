# 通话无声排查

用户反馈 ElevenLabs 语音条正常，通话没有声音，也未看到回复文字或错误。尚未取得设备日志，不能据此认定具体服务请求失败。

已确认队列播放器会吞掉 prepare/start 异常，把不存在或空音频当作成功；字幕又只在播放开始后显示，使播放失败难以识别。

本次调整通话字幕交接和播放器失败传播，保持原有语音配置与服务选择。为缺失、空音频添加回归测试；通过主分支已有双端发布流程生成应用内更新，继续使用固定签名。

设备上的具体故障仍需结合通话停留阶段、配置入口和实际调用结果核对。
