# 聊天交互卡顿修复

基于已发布的 c2567d9，保留聊天记录、角色绑定、头像设置、事件及时间规则。处理界面阻塞和重复工作，不引入引擎接入或新的用户设置。

## 修改

- 气泡头像由一个共享异步流读取名字、ID 和头像覆盖配置，不在 Compose 内 runBlocking，也不为每条消息读取完整角色设定。
- 编辑及回滚后的上下文统计异步刷新，同一窗口连续请求取消旧估算；消息修改和回滚仍完成持久化后返回。实际发送所需的上下文计算保持原调用语义。
- 原生聊天区改用 LazyColumn。固定头尾各一项，保留原始消息索引、隐藏消息、重复时间戳键、历史分页、收藏跳转及底部跟随；不再保存全体消息的绝对像素坐标。
- 状态卡片与详情复用后台计算好的时间线，点击曲线不再扫描近期事件。
- 一次工具完成产生的通用事件和领域事件在同一状态文件事务中写入，保持顺序和触发语义。
- 手机感知运行期只在状态文字改变时访问状态文件，减少两秒轮询的无变化读取；失败不更新已发布状态，下一轮仍可真实重试。

## 验证

新增设备测试覆盖真实消息列表容器：大量消息不全部创建、跳到远处消息、相同时间戳不冲突、前插历史保留稳定消息锚点。设备测试需设备或模拟器，CI 仅编译它们，不能当作已在手机运行。

提交前检查差异和所有调用点，CI 验证 Kotlin 编译、现有 JVM 回归、APK 打包及签名。实际手机滚动帧率和长回复、图片高度变化后的定位需安装验证；不宣称已有设备性能数值。
