实现记录：

- 共读支持 UTF-8/GB18030 TXT、带 BOM 的 UTF-16、按 spine 顺序导入的 EPUB 文字，以及当前公开网页正文。网页不自动跨章节爬取；EPUB 不导入版式和内嵌图片。来源下载保留既有公开地址、大小及超时校验。
- 长篇按章保存，导入的长章节按段落边界拆节，模型每次读取最多6000字并返回下一偏移；用户原文不截断。每次改稿保留不可变旧稿，原批注继续挂在原版本。
- 批注支持四种字体、五种颜色、照片、归一化矢量手绘。手绘同时保存 PNG，模型可通过现有 read_file 看图。工具读取批注分页，不把全部坐标塞进上下文。
- 用户读完、发布或批注才产生事件，保存草稿不唤醒；事件绑定助手、跟随最近私聊。后台沿用同一 ownership/cancellation barrier，六类来源轮转；成功只确认本批事件，迟到的新事件不会丢失。取消保留待处理；失败和超时在书页显示，可重试。
- 已接入前台服务的待处理职责，通知权限关闭时仍保留书房未读数；提醒不在通知正文展示私密作品内容。
- 新增锚点、Unicode分页、手绘边界、旧稿/并发编辑、事件去重及确认、草稿和分页读取测试。静态 diff 检查通过，本地未运行编译/测试。构建和 JVM 测试由现有 PR 工作流执行，真机选字、画板、导入与通知待安装验证。
