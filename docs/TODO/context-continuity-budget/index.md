# 上下文连续性修复

原实现压缩后只留两轮完整对话；运行态历史读取失败返回空列表，可能继续发送缺少前文的请求。

本次保留最近两轮为完整下限，按连续的完整轮次向前扩展到最多八轮。额外扩展的保留尾部按配置上下文的四分之一设置字符预算，上限 16384 字符；字符预算是保守文本估算，不是服务商精确 token 数。超长的最近两轮仍完整保留，不拆工具调用链。摘要来源与保留原文不重叠，至少留一轮供压缩。

历史读取异常现在传给已有请求错误处理，不再伪装成空聊天。数据库与用户设置不迁移，不删记忆、内部状态、工具或原始记录。

验证覆盖：多轮短讨论、预算边界、连续顺序、超长工具链和既有摘要提交一致性。原来的两轮边界测试显式使用零扩展预算。

限制：没有用户实际请求快照，不能认定提示词体积是本次体验的唯一原因。本改动不保证模型每次正确理解；已压缩的旧原话不会自动恢复到当前上下文。
