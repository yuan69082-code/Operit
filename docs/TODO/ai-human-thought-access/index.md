# 人类思考链权限

将常驻/折叠输入改为用户总授权、助手各自开启或关闭。授权默认关闭，撤销清除全部助手开启状态。称呼默认园园，双方可编辑。开启时正文必填，心里话允许空白并明确标记；关闭时只发送正文。已发布旧消息保持可读，模型侧统一转换新标记，不再沿用旧解释。权限变更不能倒退已经发送的请求。

范围：消息协议、权限存储、输入组件、助手工具、发送检查与模型上下文投影。群聊按成员各自权限投影，不使用前台角色代替执行者。沿用既有 CI 编译测试与自动发布。

实现：新增 human_thought_chain 工具，继承调用助手及会话归属校验；聊天输入按钮打开总授权和称呼设置，双栏只在当前助手开启时显示。直接发送与排队发送检查正文；关闭后按执行助手投影消息，工具续轮也重新检查。旧协议仅用于读取，模型收到新标记。群共享摘要不收入思考链，避免借共享摘要把一个成员的阅读内容交给未开启成员。

验证：静态 diff 检查；补充空白标记、旧协议迁移、合并消息过滤、授权门禁、撤销权限、助手隔离及正文校验测试。无本地 Android 编译结果，提交既有 CI 执行编译与 JVM 测试，真机交互待验证。
