## 正常接线

EnhancedAIService将真实主体帧和工具轮位置交给ToolExecutionManager。执行前SubjectActions把请求和可选__operit_action声明写入原内部状态SQLite归档；权限仍逐项执行。工具位置按帧/轮/序号确定，参数另校验哈希。同一位置技术重试不再执行；不同新请求可形成新操作。

执行后保存真实回执再交给正常工具续轮。只登记请求没有回执时保留未知，不猜测未执行，不盲目重放；外部端没有幂等保证时不宣称恰好一次。完整报告失败不删除操作记录。操作期间不持状态锁；SQLite事务只保护短读写。

原始参数和完整结果存增量action_history；当前索引保留有限结果节选。action按ID取详情，offset按SQL分页。实际结果材料与已采用decision/feedback加入第4批同一材料预算，不复制源码/完整回执到每轮。工具续轮SubjectToolMaterials只登记实际提供的返回，未知不冒充完成。

decisions保存主体明确表达的考虑、选择、暂缓或结束，不另建待办调度。action_feedback只有本轮实际收到的操作来源可引用，与原updates/inner/episodes/unions在同一报告事务采用。它是主体后来的理解，不能由工具成功自动产生。仍为轮末采用、下一轮读取，已有工具续轮可在本轮读取即时回执，没有额外模型调用。

## 软件能力

原脚本、工具包、日记和探索仍走原工具，__operit_action可关联意向及能力标识，不把所有工具调用叫器官成长。

companion_software复用原ExpressionParser，保存不可变的纯算术模板版本并真实运行。build只解析和保存，run核验版本、输入后计算，previous_version保留调整关系。产物按助手隔离，无网络、文件访问或全局计算器变量能力，不是新的通用执行平台。原脚本环境仍独立使用。产物、操作回执和主体理解分别保存。
