## 正常接线

EnhancedAIService将真实主体帧和工具轮位置交给ToolExecutionManager。执行前SubjectActions把请求和可选__operit_action声明写入原内部状态SQLite归档；权限仍逐项执行。工具位置按帧/轮/序号确定，参数另校验哈希。同一位置技术重试不再执行；不同新请求可形成新操作。

执行后保存真实回执，再交给正常工具续轮以及观察用钩子。typed result 保留原有本地查询证明；原工具返回的 success 与归一后的 executionStatus 分别保存，终端超时为 unknown，非零退出码为 failed，多段成功/失败并存为 partial。临时流式内容不作为完整回执。最终回执消息把持久 ID 放在有界正文之前，超长结果仍可按 ID 查询。

只登记请求没有回执时保留未知，不猜测未执行，不盲目重放。companion_software build 可核查该请求已经写出的不可变产物；产物内 build_request_id、主体、源码、前版和哈希必须一致，另一次同源码构建不能充当证明。确认后追加完成版本，原未知记录仍在历史中。没有可查询事实的外部端继续 unknown，不宣称恰好一次。完整报告失败不删除操作记录。操作期间不持状态锁；SQLite事务只保护短读写。

原始参数和完整结果存增量 action_history；当前索引去掉参数和 typed payload，只保留有限结果/错误节选及声明。action 按 ID 取详情、offset 每页8条；action_versions 按单次操作 ID 查询增量过程。SQL 使用索引和 LIMIT，不读全历史后截断。当前状态与历史在同一短事务写入。

实际结果材料与已采用 decision/feedback 加入第4批同一材料预算，默认2048、上限16384 Token，沿用原计量/估算及完整窗口检查，不复制源码/完整回执到每轮。普通请求候选仅取近期8项操作、各8项已采用决定和理解，再由统一预算选择；没选入可通过原内部状态工具分页取回。工具续轮 SubjectToolMaterials 只登记实际提供的返回，未知不冒充完成。群聊只提供该群内该助手的操作，私聊操作和私人决定/理解不进入群聊。

decisions保存主体明确表达的考虑、选择、暂缓或结束，不另建待办调度。action_feedback只有本轮实际收到的操作来源可引用，与原updates/inner/episodes/unions在同一报告事务采用。它是主体后来的理解，不能由工具成功自动产生。仍为轮末采用、下一轮读取，已有工具续轮可在本轮读取即时回执，没有额外模型调用。

## 软件能力

原脚本、工具包、日记和探索仍走原工具，__operit_action可关联意向及能力标识，不把所有工具调用叫器官成长。

companion_software复用原ExpressionParser，保存不可变的纯算术模板版本并真实运行。build只解析和保存，run核验版本、输入后计算，previous_version保留调整关系。产物按助手隔离，无网络、文件访问或全局计算器变量能力，不是新的通用执行平台。原脚本环境仍独立使用。产物、操作回执和主体理解分别保存。
