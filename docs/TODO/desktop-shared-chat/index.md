# 电脑独立运行与共享会话

用户要求电脑端在手机软件关闭后仍可独立聊天，手机与电脑内容互通；电脑端必须能感知和操作电脑。更新统一版本和发布，不维护两个独立产品。当前没有VPS，共享服务先运行在Windows电脑，电脑关闭时该服务不可用。

原WebChat依赖Android中的WebChatHttpBridge和Room数据库，不能只给网页套一个窗口就称为独立PC端。第一阶段保持现有手机本地聊天可用，新增独立Node服务并复用WebChat协议、已有Windows命令/文件工具。手机增加共享聊天入口，直接访问同一个服务。原生手机聊天数据不做无条件数据库替换；首版提供显式导入文字记录，原记录保持不变。

作用域：desktop共享存储、模型请求和电脑工具；web-chat跨客户端刷新和服务设置入口；Android共享聊天入口；Windows便携包和同批Android构建。服务配置和会话持久化在用户目录，更新包不包含用户数据。第一版模型传输为OpenAI兼容chat/completions；系统提示词由用户迁移，不能新建一套替代主体的角色设定。

引擎保持独立仓库，本阶段不修改或假装接通引擎。未来引擎负责主体运行，Operit负责通讯与设备工具；电脑工具必须标明pc设备，不能伪装手机控制已经执行。

验收路径：电脑启动共享服务并完成模型配置；电脑发消息后手机共享入口可见；手机发消息后电脑可见；手机关闭不影响电脑聊天；同会话并发发送有明确忙碌状态；电脑工具返回真实结果；数据在重启和更新后保留；手机与Windows产物具有同一版本与源码提交。通话、摄像头、长期记忆折叠、完整原生Android界面共享化另行适配，不在首版虚报已实现。

自动检查包含存储持久化、HTTP鉴权和跨客户端可见性、同会话并发、流式工具响应与网络失败。按AGENTS约定不主动执行本地编译/测试命令，由开发分支自动工作流验证。Windows GUI能力需要真实桌面实测，云端runner不当作完整GUI验收。
