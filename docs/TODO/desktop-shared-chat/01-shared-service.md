# 独立共享服务

旧实现：网页的模型调用与记录依赖Android服务，电脑不能在手机退出后独立运行。

新实现：desktop/src中的Node服务持久化配置、模型上下文和消息，提供现有WebChat协议。模型接口和角色提示词由用户显式配置；不自动替代原有角色设定。附件上传、消息分页、同会话生成锁和失败响应有独立实现。旧文字历史可显式导入，原记录保留。

作用域：desktop/src/store.cjs、server.cjs、model.cjs、theme.cjs、setup.html。完整旧附件迁移、语音通话、长期记忆折叠尚未纳入。

检查：自动工作流验证存储重启、鉴权、跨客户端可见性、同会话冲突和模型接口失败。Windows真实桌面不以构建成功代替验收。
