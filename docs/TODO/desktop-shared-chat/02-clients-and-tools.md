# 两端入口与电脑工具

旧实现：Android保有本地会话，WebChat依附手机；已有Windows控制代理提供命令和文件模块。

新实现：手机新增SharedChatActivity与共享连接卡，WebChat在共享服务上定时刷新当前会话。保留原生手机本地聊天和接口。电脑复用既有命令、文件模块并增加截图、点击、键盘工具；工具结果进入模型后续请求。多显示器截图带原点和尺寸，模型点击使用绝对坐标。

作用域：Android外部HTTP设置与私有WebView入口、web-chat共享刷新和设置入口、desktop/src/tools.cjs。未把手机控制工具伪装成电脑能力，也未接通独立引擎仓库。

检查：自动工作流核对WebChat类型与构建，并在Windows验证实际文件读写和列目录；屏幕、鼠标键盘操作仍需真实桌面实测。
