# 同批发布

旧实现：个人安卓包独立构建与发布，没有独立电脑产物。

新实现：desktop/release.json定义版本基数和协议；共享工作流在开发分支及main按同一提交构建Windows便携包和固定签名安卓包。两者通过后才生成共享清单并发布。配置和记录放在用户目录，更新程序包不会替换用户记录。共享页面按清单的版本代码提示更新。

作用域：共享工作流、复用安卓工作流、Gradle版本来源、启动脚本和更新检查。旧安卓push构建交由共享流程；手动安卓构建仍可使用。不同工作流的并发组独立，避免跳过的旧流程取消共享构建。

验收：Windows检查与打包通过；安卓签名、版本一致性与发布以GitHub Actions结果为准。首次运行仍需用户填写模型接口及原有提示词。当前不自动安装或后台替换客户端。
