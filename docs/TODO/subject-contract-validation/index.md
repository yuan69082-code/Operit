# 主体输入契约与保存故障修复

基线：7bad2eeee66d9fc47966e15efa71601b0e2d8e7c。只修改 Operit。

实际故障：心理事件正文约 800 字符，宿主附加两份来源后超过 5000 字符，报告被整体拒绝。联合存在相似的附加来源计量问题；决定/反馈有未公开的每轮 4 条限制。行动声明和生活续接的参数错误没有可操作诊断。

1. 修复事件/联合的宿主材料误计量；完整来源与历史保留，常规选材不重复装载来源快照。
2. 核对人格、偏好、关系、事件、联合、决定、反馈、经验、方向及工具声明的输入契约；去除重复的内容/条数门槛，保留模型报告预算、身份/来源/版本与跨轮采用。
3. 用可按需查询的契约提供准确类型、字段与必要边界；错误指出具体字段与改正办法，不复制私人原文进入诊断。
4. 区分旧梦记录和参与式梦过程，修正步骤查询与梦境操作的提示。
5. 合成数据复现、针对性回归、整体冲突审阅与仓库发布流水线。不得提交用户日志或私人聊天内容。

不自动重试外部操作，不自动采用失败报告，不清空历史，不另建记忆系统。外部 ob:hold 标签行为在缺少实际失败参数时不臆改。

## 核查结论与改动范围

- CategoryEvents：取消把两份宿主来源快照计入5000字符的检查；InnerInteractions同类12000字符检查一并移除。轮末报告本身仍最多16384个UTF-16字符，来源、版本和原子提交校验保留。
- 去掉额外的叙述短字数限制，以及来源/对象/目标/关联的4、6、8、16、32条局部门槛；包括决定/反馈和醒后理解每轮4条。统一受输入预算约束。重点位3..6、梦境步骤1..6、单次工具执行和调度额度等有具体含义的边界保留。
- 人格、关系、偏好：原文无缩写，候选可替换，已采用内容仍须明确新候选和跨轮采用。48小时已有内容承接是用户已确认的规则，不取消。补充候选未读取、引文不符、来源缺失等可操作诊断。
- 新增只读get section=contract，按inner/episodes/unions/action/life/rest/foundation/legacy查询。常驻提示只加入口，完整细则不全量注入。工具续轮最近24份来源绑定的已有资源边界在细则说明，历史仍保留，可重新按需读取。工具声明的capability.version只是标签，现接受字符串或非负有限数字并原样保存；intention_refs.version仍是实际整数版本，空引用数组仍合法；无效声明拒绝执行，不暗中剥掉声明重试。
- 梦境步骤查询必须指定过程ID；静态梦记录不能冒充运行过程。保留原睡眠/调度行为，仅修正说明和错误。来源快照在当前选材中省去，完整原文仍能通过原事件/版本查询；私域来源标记在精简前保存，不因减小上下文失去可见范围。
- 查明一处原说明冲突：基础求生欲已有foundation报告入口，联合说明却写成只能候选采用。说明现与两种实际权威入口一致，没有新增自动改值机制。
- 旧兼容维度的64个活跃定义边界不等于新inner/episodes上限；保留兼容运行并在按需细则说明，未重新开放旧工具的create/revise入口。未改记忆MCP、人格数据结构、已采用历史、界面或连续性引擎。
- ob:hold标签反馈：提供的日志没有截图中失败调用的参数/原始回执，Operit仓库未找到该外部工具实现；不能据聊天自述判定由客户端改写，不改外部服务。
