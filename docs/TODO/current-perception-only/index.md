# 只携带本轮感知

自动注入把屏幕 OCR、当前应用、通知和设备状态与相关记忆放进同一附件。此前旧附件跟随聊天历史反复发送，使正常聊天和后台自主活动的请求持续携带过时屏幕。

在 EnhancedAIService 的最终输入处理完成后、相邻用户消息合并之前，统一筛选自动注入附件。用量预估和实际发送使用同一筛选规则。

仅当前用户输入或当前自主唤醒对应的输入保留完整自动感知，工具续接继续使用该轮快照。新输入未附带感知时不沿用上一轮屏幕。历史自动附件只保留相关记忆段；普通附件、聊天正文、摘要及助手回复维持原样。过滤只作用于请求副本，不改写已保存的聊天。

本次不更改截图或应用事件的采集频率、唤醒频率、模型选择、摘要审阅和自主活动机制。旧感知不再直接供后续请求回看，系统也不会因此增加每次应用切换的模型调用。

已添加回归用例，覆盖旧屏幕过滤、中文和英文记忆保留、普通附件、工具续接、未采集新感知及重复处理。未在本地运行编译或测试；遵循仓库默认执行规则，提交后的 CI 结果另行确认。
