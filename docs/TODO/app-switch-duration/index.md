# 应用切换时长与短跳转合并

原先本机日志保存停留时长，但唤醒事件投影只保留应用名称和时间，助手收不到上一段的时长。Activity 暂停后等待一秒就结束区间，也会把权限弹窗误当成离开应用。

本次沿用手机感知的设置、助手路由与使用记录，不新增开关或修改用户配置。

## 范围与实现

1. `PhonePresence` 以进入下一应用或桌面的时间结束上一段，同包 Activity 切换不另开区间，取消以 pause 结束区间。
2. `PhoneAwarenessRuntime` 合并使用记录和广播中的亮灭屏、锁定边界。锁屏或灭屏立即关闭区间；屏幕关闭时忽略应用进入事件，亮屏但未解锁时暂存前台进入记录，解锁后从解锁时间开始计时。采集缺口不虚构时长。
3. `PhoneEventQueue` 对应用进入等待五秒。已结束且不足五秒的区间只合入后续批次，不单独唤醒。原始事件不删除、不把短跳转时长加给另一个应用。
4. 切换的 `previous_app` 附带 `entered_at`、离开时间 `at` 和 `duration_ms`；`completed_visits` 合并尚未报告的结束区间，包括回桌面及锁屏前的区间。每个数组最多呈现最近十条，计数指明实际数量，完整日志仍通过现有 `events/usage` 查询。
5. 关闭感知或撤销待处理任务时，同时取消尚未投递的短跳转。保持现有回桌面、回本软件只记录不主动唤醒的规则，时长随下一次有效批次送达。
