# 独立助手工作区与主助手

第 55 版的聊天归属已经隔离，但记忆页面和部分功能选择仍引用全局设置；包和 MCP 的启停会影响其他助手。模型切换仍沿用固定绑定及解除确认，不能满足每位助手自由选择的要求。

本次将记忆页面、模型与功能选择、内置工具、包、MCP、Skill 的选用状态按助手保存。群聊和后台任务使用实际发言助手的上下文，不随前台切换。保留已发布数据及安装身份。

用户可指定一位主助手，查看其他助手的聊天、时间和能力使用记录，并管理软件内的助手配置。主助手资格由用户界面授予和撤销，普通助手不能自行提升身份。

实施和验收见 [01-workspaces.md](01-workspaces.md)。
