# 实施与验收

- 核对记忆读写、记忆页面、模型切换、功能映射、工具选择、插件启停的实际读写路径。
- 保持助手稳定 ID，使用独立记忆空间和独立可修改的选择状态；保留旧记忆及原有配置，不将混合旧数据凭空分配。
- 区分已安装能力与助手选用状态，取消选择不停止其他助手仍在使用的服务。同步调整聊天入口、设置页面及 AI 设置工具。
- 去掉聊天模型切换的锁定及解除确认，将切换保存到当前助手；群聊成员与后台任务根据自身身份解析设置。
- 增加主助手指定入口、跨助手查询与管理工具、身份校验和分页记录读取，包含时间及工具使用。
- 为隔离、并发切换、迁移和主助手权限增加有意义的检查，执行现有测试及签名构建，发布可覆盖更新。
- 记录自动检查及尚未完成的手机实测。
