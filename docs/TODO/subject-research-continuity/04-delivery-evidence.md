## 贯穿五轮的自动化证据

SubjectGrowthFlowTest 走 EnhancedAIService、共享流、MessageProcessingDelegate、生产 ToolExecutionManager、companion_todo/companion_explore/companion_software/companion_internal_state、原归档与报告采用：

1. 正常输入中保存研究事项，保存本身没有预约；随后明确安排才取得时间和用途回执。
2. 到期入口认领预约，无新用户消息，读取先前决定和进度，保存研究批注及后续安排。
3. 真实构建算术能力并运行得到 26.5；回执先保存，模拟模型提出经验与方法候选。
4. 下一业务轮取得经验并通过正常工具读完整候选；调整能力版本并真实运行得到 11.5，随后采用对应完整版本。
5. 请求实际包含采用后的方法及例外，模拟模型选择暂停事项和探索；受控时钟推进 30 天不自行重启。

模型输出与到期时间受控。ConversationService 准备适配器使用生产 InnerStructureContext，未覆盖图像处理或整个通用提示词组装；其他既有入口测试分别覆盖 CompanionContext。此测试没有运行完整 Android 后台服务，也不能证明模型自己发现了方法、手机准时启动或长期成长。

## 私人历史与性能

园园明确批准的迁移只接管已启用连续性助手的私人任务和阅读来源、目录、进度/随记版本。复用现有 internal-state-history.sqlite 与 history 表。当前索引、完整历史、旧文件检查点分别保存；每次变更原子写入当前与历史。恢复按稳定 ID 跳过已经提交的记录，关闭开关不复活旧副本。旧程序已经丢弃的内容无法恢复。

自动化通过正常工具/保存入口建立 321 个事项、65 个来源、206 个旧待读条目及超过 80 条的批注；检查分页、未加载事项关联、页外预约、100 条并发批注、两位作者的阅读随记、迁移中断重入、私域隔离及完整备份恢复。新增旧版本和保留线索在群聊不可取回；私人任务/来源材料也带私域归属，群请求不注入正文。明确删除保持原语义，删除与解除关联同一事务；沉淀资料库有稳定回执，重试不重复创建。

六类相关索引共用每助手 1,048,576 的估算权重，最多四助手缓存；这不是实测堆字节数。容量不足只淘汰可重建索引。5011 条归档测试覆盖相关取用、失效、分页、重开和多助手隔离。当前正文按原统一 2048 默认 / 16384 上限 Token 材料预算选入，完整模型窗口仍另核。地方页数不是心理重要性，不清理经历来减负。

实际限制：首次迁移需扫描旧文件；当前头索引冷建与 SQL 文本检索随当前记录数量增长，不能宣称固定时延。历史先 SQL 分页再解析，不先全量加载。书房整书扫描、原资料库保存行为、未启用助手及群任务未改。Android 设备上的帧率、耗电、长期数据库增长未实测。
