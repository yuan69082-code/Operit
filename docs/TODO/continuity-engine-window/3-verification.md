# 验证与正式接续

本批验证使用本项目自己的临时数据和模拟接口，不运行引擎仓库。

需要覆盖默认关闭、关闭后不请求、重启保留绑定与事件、重复事件冲突、未知结果查询而不重发、主体或关联变更隔离、授权撤回、错误回执身份拒绝、模型不代答、健康检查不冒称接通，以及既有普通会话兼容。

正式接续前需要引擎提供正式主体绑定确认、版本和事件支持声明、结果查询与最终表达的协议。随后实现相应生产适配器；先私聊联调，再验证群聊与感知。不通过修改引擎冻结接口或伪造固定测试身份绕过这些前置条件。
