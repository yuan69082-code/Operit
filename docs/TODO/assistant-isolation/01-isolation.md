# 实现与验收

- 排查新建、激活、历史选择和发送链路，将会话归属绑定到稳定助手 ID；兼容旧版按名称保存的记录，不删除或重写聊天正文。
- 从助手选择器和设置页切换时打开对应会话，无历史则新建空会话；选择历史则恢复所属助手。发送不可把另一助手的会话重新绑定给当前选择。
- 新助手使用独立模型配置副本、空记忆空间和独立工具选择。检查成员在群聊中的模型、记忆、能力以及资料库、表情库的作用域。
- 聊天页面直接选择多个助手建群，保留现有群组管理，群聊使用独立历史。
- 自动检查归属、旧数据兼容、切换和群组约束；执行安卓测试和构建，核对成品签名并发布更新。记录未进行的设备验证。

旧版已经混写的内容不能凭空推断所属助手；保留原文与管理入口。既有用户主动配置的共享项必须与新助手默认隔离区分处理。

## 实现记录

聊天元数据新增 nullable `characterCardId`，数据库从 21 升级到 22，仅增加列。旧名称只在唯一匹配时补齐 ID；无明确归属时使用未分配标记。群聊以群 ID 为归属，不能算作默认助手的空名称私聊。导入、导出、分支、批量转移与解绑均保留或明确更新归属。

选择助手与选择会话统一联动。切换过程串行执行，旧窗口回调核对最新持久化会话 ID；前台发送核对当前目标，后台请求核对所属助手或群成员。重试生成也限制在所属助手和群成员内。群聊异常留在群聊并显示错误，不再转成普通单聊发送。

新助手的模型配置保存独立副本，记忆空间和档案为空，工具选择独立，MCP 初始不勾选。旧助手只迁移一次跟随全局的选项，已有固定绑定保留；之后用户仍可主动选择共享。普通文字和语音提示都使用所属助手的模型、记忆。新助手表情库初始化内置内容；明确复制助手时才复制原助手表情收藏。

资料库、表情库、XC 绑定沿用已有按助手 ID 的作用域。历史查询工具过滤私聊和群成员范围，记忆工具优先采用可信调用身份；后台主动活动从聊天元数据取得身份。用户在管理页面仍可查看全部记录并手动调整归属。

## 使用入口与限制

点击聊天顶部助手区域，在选择面板点“创建群聊”，填写群名并选择至少两位助手。群成员使用各自模型和能力，回答顺序沿用已有“角色回答规划”功能配置。群聊历史共同可见，成员各自私聊不会加入群上下文。通过设置中的群组页编辑成员。

已有混写记录不自动拆分，原共用记忆空间不删除也不向新助手批量复制。外部 MCP 服务器、模型服务本身不由本地助手隔离改造；明确给多位助手选择同一记忆空间或外部服务，是用户选择的共享。
