# 助手隔离与群聊

已发布版本 1.12.2+51 中，助手选择与聊天选择是两个可独立关闭的行为，设置页激活助手不会同步会话；新助手默认跟随全局模型、记忆和工具配置。群聊也可错误地接管当前单聊。

改为按持久身份选择独立会话，发送由会话的归属决定。新助手独立保存模型配置、记忆空间和工具选择；保留原有记录和已有明确绑定，不自动复制其他助手的历史。增加直接创建群聊的入口，群聊独立保存消息，各成员沿用各自配置。

实现和验收见 [01-isolation.md](01-isolation.md)。沿用个人版包名、固定签名和应用内更新流程。
