# 通话文本回调的生命周期

截图出现ClosedSendChannelException。通话控制器在生成任务退出时关闭句子通道，但onVoiceCallText由消息服务协程调用；挂断、打断、输入错误或超时让sendVoiceCallTurn先退出时，服务仍可能交付后续句子，向已关闭通道发送。

sendVoiceCallTurn为文本交付建立属于本轮的子任务。服务回调在该子任务中执行，并等待交付完成。退出本轮时在不可取消的清理区取消并等待所有交付结束，之后调用者才会关闭句子通道。迟到回调不再进入上一轮的播放队列。活跃服务自身的取消仍传播，正常文本投递异常仍传播，不吞掉ClosedSendChannelException。

此次仅修复回调与通道的所有权，不修改分段时长、角色或语音接口。审阅正常完成、回调等待队列、挂断/打断取消以及超时退出路径。按仓库执行准则未运行本地编译或测试命令；提交触发既有自动检查。手机上仍需验证长回复播放中打断或挂断的行为。
