# 不完整音频分析结果的错误范围

截图中的“音频分析没有返回完整的说话者和声音信息”来自结果解析，不代表麦克风故障。原实现将解析异常交给持续收音任务的总错误处理，取消整通电话的采集与回复。

此次保持完整字段及声源标签校验，给解析失败建立独立异常类型并保留原始原因。持续分析循环只捕获这一类型，拒绝该窗口、提示该段未发给模型，随后处理下一段真实录音。采集仍运行，当前回复不取消。未填充缺失字段、未发送部分原话、未重试或切换模型。HTTP、网络、采集与其他异常继续走原错误路径。

无效窗口和声音参考仍在 finally 中删除；待分析语音计数仍递减并更新接话状态。取消优先传播，静音或已过期窗口不提示错误，也不交付声音观察。

这项修正解决单个不完整结果导致整通电话暂停的问题，不保证模型以后不再产生格式错误，也不能恢复已经拒绝片段的原话。未取得当次服务原始响应，尚不能确定是哪个字段缺失或 JSON 格式错误；日志现保留解析原因供后续定位。按仓库执行准则未运行本地编译或测试，自动构建与手机实测待确认。
