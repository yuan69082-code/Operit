# 通话内打字

完整通话界面与悬浮小窗新增“打字说话”，共享当前通话的文字草稿和发送队列。文字仍由通话控制器通过绑定会话与角色发送，回复沿用当前通话语音播放。

文字输入独立标记voiceCallTyped，模型收到明确的打字来源说明，聊天记录显示“语音通话 · 打字”。不把文字当作音频分析，不用文字建立声音参考，不从打字推断语气或音色。通话、摄像头与静音状态不因发送文字改变。

等待收音时发送文字，结束本次录音等待后处理文字；AI正在回应时先排队，不自动打断它。静音时也能发送并听见语音回复。挂断会清理本次通话尚未处理的队列。队列满时保留草稿并提示，不静默丢弃新消息。

完整界面适配键盘遮挡；悬浮窗仅在展开输入框期间获取键盘焦点，收起或隐藏时释放，继续保留通话服务。窗口隐藏前先清空视图引用，避免输入框释放焦点时操作已移除的窗口。

已审阅三种收音模式、静音、开场、忙碌排队、输入来源和窗口隐藏的调用路径。按仓库约定未主动运行本地编译或测试命令；依赖提交触发的现有自动工作流检查编译。手机键盘、悬浮窗尺寸及语音回复仍需安装后验证。
