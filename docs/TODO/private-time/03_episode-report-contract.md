# 心理事件报告契约修复

日志复现：同一事件先采用为 foundation:emotion:sadness，下一次报告省略 goals 被拒绝，后一次沿用原 ID 改成 foundation:sentiment:attachment，被通用 ISR_SEMANTIC_RULE 拒绝。发给模型的规则未解释稳定事件不能直接换类别，通用错误也没有提供改法。

- 保持事件原类别及历史；换一种体验用独立事件和 same_matter 关联，原体验可按主体判断更新。正常请求和按需 contract 使用相同说明，不新增模型调用。
- 类别变化、愿望阶段、重点容量/归属、相关事件关系及不合适的来源返回固定规则码、具体字段和操作提示；提示不拼入私人原文。已有失败通知进入下一轮状态材料。
- objects/goals 是可选关联，新建省略表示无关联，更新省略保留原值，显式 [] 清空；提供 null 或字符串仍明确拒绝。不要求心理体验必须有目标。

验证：模拟模型经正常报告解析、采用和下轮 prepare，检查拒绝时原记录不变、规则和修正提示实际送达、同事不同类别分别采用且历史保留；覆盖关联省略/保留/显式清空和错误类型。没有使用用户私人聊天作为提交到仓库的测试数据；没有真实模型自主纠正的验证。
