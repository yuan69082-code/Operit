# 自由时间设置与私域读取修复

基于 main fdcd1a55。范围：既有设置可用性、休息梦境读取开销、摘要称呼。不调整心理规则、工具权限或活动调度，不修改引擎。

- 记忆来源选择本助手已经启用并获准使用的本地能力、MCP或工具包；不调用外部服务、不获取密码、不猜文件路径。沿用 memory_location 字符串，原说明可继续编辑。疲劳选择分页显示已有事件的内容和强度，沿用原 ID 存储；未选择不影响定时睡觉询问。
- SubjectLife.rest 与 rest/dream/dream_understanding 查询流式读取原 AtomicFile 的主体归属和 category_commit，跳过其余事件/报告/曲线字段，再按原提交恢复 SQL 索引。不复制第二份权威、不删除历史、不隐式推进心理状态。其他内在查询保留原时间投影。
- SQLite现有表和索引使用 user_version=1 标记初始化完成；旧库只补齐原有建表/索引并设置标记，不重写记录。后续新增 schema 需要提高版本。每次查询不再重复执行所有 DDL。
- 首页/休息状态在页面进入后台后暂停轮询，待发送消息展开后才加载；未变化的状态不因 JSONObject 引用不同而反复重绘。
- AIMessageManager 的程序追加对话回顾和普通源消息标签共用 SummaryAddress；分段摘要、草稿和审阅采用同一称呼约定，缓存指纹包含称呼。助手写“我”，用户用保存称呼，未设置用“你”；第三方引用及群聊署名保留。设置位于私域→人格与自我→对话回顾称呼，按助手保存。

验证：增加正常梦境报告采用后的轻读取/索引中断恢复/助手隔离测试，旧数据库索引初始化兼容测试，以及称呼持久化、分段消息标签和引文不改写测试。完整编译和回归由本次PR的同提交CI执行；没有手机耗时对照或真实模型验证，不宣称所有卡顿已经消失。
