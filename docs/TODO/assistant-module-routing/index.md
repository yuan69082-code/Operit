# 模块绑定助手，执行跟随活跃私聊

所有模块的助手目标只保存助手身份。统一记录用户实际选择的私聊，感知、主动联系、自主探索与私人待办共用该路由。后台回复不改变活跃窗口；群聊不替换助手私聊目标。历史回查、消息落库与正在执行的一轮仍保留真实窗口 ID。

旧安装已使用现有设置，因此保留旧助手身份和主动联系预约并做一次迁移。设置界面直接列出助手，不要求先打开指定窗口。用户换窗后不重置预约、额度或资料。运行中的后台工作因用户切换而取消，下一轮重新定位。

作用域：助手窗口路由、会话选择、感知目标、主动联系预约、自主探索执行、私人待办投递与对应设置文案。工作流调度未保存聊天窗口目标，不需更改；历史检索与群聊的显式位置参数继续表示原数据位置。

验证：静态检查与调用路径审阅；遵守 AGENTS.md 不执行编译、构建或测试。设备验收：同助手 A/B 私聊切换、另一助手隔离、群聊不抢目标、后台回复不抢目标、重启迁移、窗口删除和预约跨窗。

已实现统一助手路由，接入主页面、悬浮窗选择和真实用户发言。感知、主动联系、自主探索与私人待办投递使用相同目标；主动联系计划改为助手级键，旧目标的助手归属与原预约一次迁移。自主探索仅在认领执行时记录本轮窗口，不再把配置窗口当授权条件。状态与资料页、感知与探索设置直接选择助手。资料库、待办、XC、阅读等已有助手级存储继续按助手使用。

静态差异检查通过；更新了探索策略与存储的既有测试调用，补充跨窗口预约/额度保持及路由状态不会递归触发软件事件的回归用例。未执行这些用例、编译或设备验证。接口继续保留工具原有参数，历史窗口 ID 仅作回查和本轮落库定位；未改用户工作流内部显式编写的工具参数。
