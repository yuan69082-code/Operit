# 实施顺序

1. 对所有发送者执行隐藏消息标记；保留模型历史。
2. 存储按文件隔离锁，调度 I/O 离开主线程；发送与撤销使用同一所有权边界。
3. 各唤醒来源轮转；中断安排带标识恢复，显式安排或取消优先。
4. Gemini 将自由对象作为 JSON 文本传输，工具执行接口保持不变；修正工具结果排列。
5. 状态目录提供可报告条件方向，拒绝保留具体诊断。
6. 429 延迟重试支持服务端等待时间；取消及时关闭网络请求。
