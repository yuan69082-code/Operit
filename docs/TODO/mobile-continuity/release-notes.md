本版更新群聊连续性、助手管理、关系网和群内游戏。

- 群成员延续自己的私聊上下文与个人记忆；默认全员回应，支持 @ 单选和多选。私聊顶部可查看参与过的群记录。
- 群设置可开启持续讨论及成员主动开话题，支持暂停、继续、结束和可选限额；活动记录显示唤醒安排、发言、用量、延后与失败。
- 主助手可以创建、删除其他非系统助手、查看和修改角色设定、拉人或踢人；用户也可从群成员页面调整成员。
- 新增可视化关系网，分别保存各助手对彼此的关系、看法、进展和共同经历。用户与主助手可全局管理。
- 新群消息用固定身份记录来源；群摘要逐人署名，主助手读取他人记录明确区分观察与亲历，普通私聊仍保留自身第一人称。
- 群游戏支持斗地主、简化狼人杀、情景玩法与自制规则模板。隐藏身份和手牌按玩家分别提供，公开记录过滤私密工具参数。游戏身份不改变日常身份。
- 已有聊天与配置原样保留。旧群消息缺少身份依据时标为未知，不凭名字自动认领。主动群活动依赖应用前台服务运行。

入口：群聊顶部的 @、群设置、成员、关系网、游戏、活动记录；私聊顶部的关系网与群聊记忆。

本版补齐独立助手的记忆与能力配置，并新增主助手。

- 每位助手使用独立记忆库，记忆页面、自动记忆、查询和重建均按当前助手读取。发现旧助手共用记忆库时分配独立空间；旧记忆原文保留，不自动复制其他助手的记录。未分配的旧记忆库可由用户选择归属，同一库不能同时分给两位助手。
- 聊天模型可直接自由切换；摘要等功能模型、思考和工具开关、内置能力、包、MCP、Skill 的选择分别保存。群聊、后台唤醒、摘要和工具执行均沿用实际执行助手的身份，切换前台不改变正在进行的任务。
- 取消某位助手对包或 MCP 的选择不会停止其他助手正在使用的服务。安装的能力和模型供应商目录仍由软件统一管理；从软件彻底卸载能力或删除供应商配置属于全局管理操作。
- 设置 → 角色卡编辑 → 角色卡页可指定或取消“主助手”。主助手可按需查看其他助手的聊天、时间及工具调用记录，查看模型目录，调整各助手的模型和能力选择。权限仅由用户授予，每次调用重新校验；普通助手不能冒用身份、自行提权或读其他助手的私聊。
- 跨助手记录分页按需读取，不在每轮自动塞入全部聊天；主助手的跨助手查询不会把其他助手的内容自动写成自己的记忆。删除主助手会同时撤销主助手资格。

沿用原包名和固定个人签名，可直接覆盖更新。自动测试及构建检查不替代手机实测，特别是第三方 MCP 服务、群聊并发和后台唤醒的实际运行。

上一版表情包功能：

- 聊天加号新增“表情包”：分开查看“我的”和当前 AI 的收藏，点图预览后添加到消息，再点击发送。支持从相册批量添加和自定义分类。
- 聊天中的图片与表情点开预览，点击爱心即可收藏到自己的表情库。支持 JPG、PNG、GIF、WebP，保留动图原文件；同一收藏库中的重复图片不重复保存。

- 用户收藏与 AI 角色收藏独立保存；保留现有 AI 表情库。新发送的表情保存独立副本，删除收藏不影响已发送的消息。
- 不在每轮附带整份表情库，按需分页读取，避免随着收藏数量增加而持续增加上下文。
