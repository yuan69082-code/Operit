# 手机端状态延续与主动交互

## 原状与目标

当前角色提示、记忆库、摘要、来电工具已有基础能力，但缺少统一的角色状态持久化、静默唤醒、可管理的资料附件和事件主动联系。保留现有接口与用户数据，在原手机版增量实现；不涉及两个仓库的电脑端。

情绪延续、软件主动联系和能力感知各自可关闭。情绪直接对接角色绑定的 XC 实例，软件仅保存同步回执，不运行第二套情绪状态；无角色卡的绑定按会话保存。资料库按角色保存，情绪与资料库提供可视化页面。

## 实施单位

1. XC 角色绑定、自动读取注入、真实互动回传及情绪可视化。
2. 通话静默回调：说话、生成、播放期间不触发；静音和挂断停止；允许 AI 保持安静。
3. 角色资料库：自定义分类、文本知识/能力记录、文件副本、检索与管理。
4. 软件主动联系：有开关的运行时空闲与事件唤醒，AI 决定安静、消息或来电；不依赖用户创建工作流。没有数据源时不声明具有心率感知。
5. AI 可维护保留片段和摘要草稿；每次压缩还会把原文与完整草稿交给当前聊天 AI 审阅，确认或修订后才正式折叠。
6. 可开关的真实能力快照及与上轮的变化，关闭后不注入、不返回专用查询结果。

## 验证重点

同角色跨窗口及换模型、不同角色隔离；开关立即生效；资料源文件删除后副本仍在；静默回调不抢占用户发言；主动联系不会消费输入框或附件；保留文本原样跨摘要；权限和模型能力变化不会被描述为已执行的操作。

实际编译、安装和真机验证结果在完成后记录，不把源码核对写成运行成功。
