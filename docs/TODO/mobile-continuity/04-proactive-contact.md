# 软件主动联系

原来 request_voice_call 只能在模型已经运行时被调用。新增 CompanionRuntime，由现有 AIForegroundService 管理，默认关闭，且必须选择一个单角色目标会话。与情绪开关独立；未来外部引擎可接管。

后台服务观察空闲、设备解锁以及用户资料更新事件。不需要创建定时工作流，但模型仍需要软件心跳或事件才能运行。主动判断最小间隔默认 15 分钟，可选 1 至 240 分钟。额外请求使用配置模型并消耗额度，软件或系统停止后台服务后不能持续工作。

判断使用目标角色提示、最近 24 条文字历史节选、开启接续时从绑定 XC 获取的状态和保留记忆。能力快照仅在能力感知开关开启时加入。条目超过 3000 字时标记截短。采用角色固定模型或全局 CHAT 模型，无工具调用，严格解析 quiet/message/call JSON；格式无效不对外发送。

只将确认的消息存入目标会话，后台可使用现有回复通知；call 复用来电、接听、拒接与超时流程，遵守工具可见性限制。收到用户新输入、关闭开关、改目标、通话开始或聊天版本变化时丢弃已过期判断。没有新用户发言前不再次自动拨打。

运行中 Kotlin 集成点为 CompanionRuntime.publishEvent(context, source, description)，现接设备解锁及用户资料更新。没有新增未鉴权的外部 HTTP 接口，没有接入 XC 自身信号推送或健康设备。后续引擎需单独接入可信事件来源。

设置入口负责启动/刷新已有前台服务；主动联系开启时计入该服务的持续职责。关闭功能不再进行模型判断，服务结束时取消任务并释放广播监听。

源码接入完成。未验证锁屏、省电模式、系统停止服务、通知及来电体验。
