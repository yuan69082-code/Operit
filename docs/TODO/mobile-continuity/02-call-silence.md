# 通话静默回调

原来只有录音、转写、声音观察或摄像头事件触发回复。新增通话所属的静默监测任务和独立信号通道。

默认开启，阈值 12 秒，可设置 5 至 120 秒。只在接通、未静音、处于监听阶段，且没有待处理用户发言或文字时发出候选静默事件。采集音量超过原录音模式阈值时重置计时；生成、播放、静音时暂停计时。每轮结束后重新计时。

静默事件不是用户消息，不写入用户发言记录。模型可以返回 voice_call_quiet 控制标记保持安静；真正说出的回复通过已有通话事件记录入库。挂断会取消监测并清空待处理信号。

持续音频分析模式下，新语音活动可以取消仍在生成的静默回复。普通 STT 和原始音频模式沿用已有轮流收音/播放方式，本次没有将它们改成全双工，生成期间不承诺能检测新的用户发言。阈值检测也不等同于声源或语义识别，环境噪声可能延后静默触发。

需真机验证三种输入模式、用户刚开始说话的竞态、静音恢复、TTS 完成后计时、识别错误与挂断清理。源码接入完成，验证未完成。
