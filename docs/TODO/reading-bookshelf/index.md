# 阅读角书架

沿用已发布的阅读、日记与批注记录，将阅读角改成日记、待读、已读三层木质书架。竖排书脊显示真实标题，每层横向滚动，可搜索；点开后进入图文书页。助手实际写下的随记接在正文末尾，用随包中文手写字体显示日期与落款。

保留来源管理、自主探索、添加线索、日记编辑和旧稿入口。不为装饰发起模型请求，不将用户打开页面计为助手已读，不用示例文章或生成配图冒充实际材料。未来晨报有数据后再增加层。

## 实施

1. 复用现有存储接口和作者隔离；书页兼容只有正文或摘要的旧记录。
2. 新获取的网页保留段落和原文配图顺序，展示可获取的部分正文；来源链接始终可见。
3. 书架与书页共享明确的返回、阅读字号、批注保存、日记编辑入口。
4. 检查旧记录、作者与批注隔离、图文提取、字体和图片打包，并通过现有构建与发布通道验证。
