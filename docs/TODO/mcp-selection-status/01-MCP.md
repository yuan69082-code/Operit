# MCP 启动、工具发现与状态

旧实现的启动流程只读取全局 disabled，管理页开关却只写助手白名单；页面总数的 remember 未依赖助手白名单，工具数量又包含未选择服务的缓存。远程发现优先返回磁盘缓存，不能证明当前连接或工具列表可用。

计划：

- 启动与进度列表使用同一份当前助手选择快照；群聊使用成员选择的并集，工具执行仍使用具体成员的权限。
- 管理页只主动发现已选择服务，状态从运行时读取，缓存不冒充在线；工具发现失败、重连和空工具列表均能刷新。
- 已配置服务可出现在能力目录中，实际使用时才连接，避免切换助手后找不到未预启动的服务。
- 保留其他助手的连接，修复重启日志完成判定和错误说明。

验证计划：添加选择范围与运行状态回归用例；本步骤只做静态检查，单测和构建留到本批结束。

实现记录：

- 启动页和启动器共用选择快照；取消某助手选择不注销其他助手的共享连接。工具触发重启时先捕获调用者选择，防止误用前台助手配置。
- 管理页的分子、分母均来自同一助手选择，连接、工具发现、错误状态改为观察同一运行时状态。新增明确状态文字。远程和本地服务均实际请求 tools/list，旧缓存和失败的空结果不算在线证据。
- 能力目录读取已配置服务，实际激活时检查助手选择并按需启动；工具列表更新时替换旧注册，服务删除的工具不再残留。
- 按服务串行创建会话，故障连接重建时释放旧客户端；工具发现异常和取消不再吞掉。缓存状态并发更新和写入避免互相覆盖。
- 重启完成判定等待整个批次，保留失败服务及原因，旧批次结束不会清除新批次的忙碌标志。

验证记录：已完成差异空白检查、中文和英文资源 XML 解析及 8 组新增占位符一致性检查。已添加 12 个选择范围、连接状态、发现失败、恢复、取消和业务错误的回归用例，尚未运行。尚未编译、构建、推送或发布，也未连接用户手机上的 MCP 做实机验证。
