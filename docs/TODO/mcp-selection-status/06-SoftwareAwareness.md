# 指定助手的软件事件感知

## 目标

原能力感知仅在发消息时比较当前能力快照，缺少模型、设置、助手及使用行为的变化记录。增加本机事件日志、明确的观察助手、隐藏事件交付与查询入口，保留原开关；未指定助手时不得向所有助手开放。

## 实施范围

- 设置存储提交时记录变更，覆盖模型配置、助手、群组、功能绑定、权限、界面、语音以及包/Skill等偏好；记录字段变化，不复制密钥、授权令牌、提示词或聊天正文。
- 软件前后台、页面切换、私聊/群聊页面访问和实际发送分别记录。停留仅计已观察到的前台时段；意外进程终止不伪造准确关闭时间。
- 只有用户明确指定的观察助手在自己的私聊中可查询和接收事件，普通助手与群聊不得取得全局记录；观察权限不自动授予主助手管理权。
- 日志持久保存，按时间/分类/助手筛选；新事件适量带入观察助手下一次对话，或在独立事件唤醒开关开启时空闲后判断。助手可安静处理；不广播给其他助手、不生成每次操作的用户消息气泡。
- 对外部工具造成的界面变化标明可能来源，不当作用户主动聊天；对密集设置变更合并交付，避免每次保存都请求模型。

## 验证安排

按本批约定先完成代码与回归用例源码，全部问题完成后统一执行测试、构建和发布。需验证新增模型、保存/删除配置、助手增删与选择、跨助手私聊停留、前后台/锁屏/配置重建、隐藏唤醒取消、密钥脱敏与未授权助手/群聊拒绝访问。

## 已接入代码

- `ObservedPreferences` 在 DataStore/SharedPreferences 成功提交后提供前后差异，沿用既有存储与迁移；首读不伪造变更。模型记录新增/修改/删除、公开名称、模型及字段名，不记录接口凭据。助手列表变更记录所属 ID。其他偏好记录字段和非敏感布尔/数值，文本、集合、JSON均隐去正文。MCP配置文件保存、Skill及外部工具包导入/删除另外接入事件。
- `SoftwarePresence` 用单调时钟计算主界面聊天可见时长，路由离开、切助手、进入后台均结束对应区间；保活页面不继续计时。打开页面与实际发送分开，隐藏唤醒、自动续写和通话内部状态不算用户发言，代理/工具来源另外标记。只记录已观察的范围，不反推启用前的访问，不把进程被杀当作精确关闭时间。
- `SoftwareAwarenessStore` 本机保留14天、最多3000条，递增序号分页，支持按类别/助手查询。记录状态与事件处理状态分开，失败、中断不自动重跑。关闭、更换目标或清日志撤销待处理事件；查询前后验证观察权限与修订号。
- 软件感知页面可指定当前私聊所属助手，分别开启记录/对话简报和事件唤醒，并查看、搜索、清除日志。沿用旧 `capabilities_enabled` 开关，但必须明确指定观察助手；不因原开关已开就默认授权所有助手或主助手。
- 观察助手下一次私聊附带至多8条新事件简报，完整记录按需查；事件唤醒独立开关默认关，默认至少间隔60秒，可设15–600秒，等待对话/通话空闲，最多3分钟/12次工具调用。AI可保持安静。执行上下文或工具期间的变化不再次触发唤醒，运行计数/缓存不反复请求模型。
- `software_awareness` 提供状态、事件、使用统计和公开模型列表；群聊与其他助手无权查询。群聊历史工具结果过滤也覆盖此工具与原能力快照。观察他人的活动不改变经历归属。

边界：记录软件内上述保存和交互入口，不是屏幕录像或每个触控/草稿字符的轨迹；外部直接改文件不伪造成用户操作。停留统计当前为主应用聊天页面，悬浮窗口发送仍有消息事件，但不将后台悬浮服务存活时间算成聊天停留。进程停止、系统冻结或观察关闭期间不能声称持续感知。
