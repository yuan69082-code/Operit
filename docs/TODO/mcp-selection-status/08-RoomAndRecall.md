# 房间、日记、中文召回与上下文连续性

## 实施顺序

1. 扩展中文关键词召回到记忆正文，补充短名和别名，保留现有语义分支及权限范围；返回可回查的原文证据，避免不同事件合并。
2. 将公共身份层收敛为上下文连续性与事实说明，个性由当前助手的设定提供，保留摘要忠实性规则。
3. 增加助手房间、组件排序/尺寸/显示控制、主题实时预览与保存还原、逐项锁定、默认关闭的助手布置授权。
4. 增加按日期查看的助手日记、来源与作者记录，用户可编辑，AI 经用户开启后自行写或不写；接入已有后台执行器，不增加独立轮询器。
5. 补齐自主探索的来源、待读、阅读与随记界面和工具，继续使用默认关闭的按助手探索开关。普通更新进入队列，不逐条发送聊天。
6. 运行范围测试和整批 Android 构建，修复失败；校验安装包签名/版本号并发布更新。

## 验收

- 修改 A 的房间、外观、日记不影响 B；关闭授权与锁定字段后 AI 无法绕过；旧配置升级不隐式开启。
- 两字名字、正文关键词、同义语义命中及来源回查；未授权资料不能参与召回。
- 日记与阅读记录保留所有者、时间、来源；工具成功写入后才称已保存，未读全文不标记全文已读。
- 房间是可选入口，原聊天路径保留；操作失败显示原因，不假成功。
- 自动活动仍由现有调度按助手模型、权限、额度执行，关闭探索撤销预约。
