# 群记忆与群生命周期

原参与记忆只读，按助手记录参与时间及公开摘录。现在保留这些来源字段，并独立保存编辑后的记忆、是否允许删除、编辑者与时间。用户可管理全部，助手可管理自己的记录，主助手沿用管理权限。

group_chat 新增 memories、save_memory、delete_memory、group_state 操作。save_memory 使用 text 与 deletable；group_state 使用目标 chat_id 和 exists。工具执行者来自原会话归属校验，不能通过 owner 参数冒用其他助手身份。

删除只移除选中助手在该群的记忆摘要，不删除消息、群卡和其他成员记忆。删除水位与后续观察在同一个存储事务里处理，旧历史快照不能重新生成已删除摘要；新参与可以形成新记录。手动编辑与自动摘录分开保存，回忆时优先使用编辑内容。

群结束状态保存在 CharacterGroupCard.ended，旧卡缺失此字段时仍开放。状态修改独立于群资料表单，编辑群名等操作不会用旧表单覆盖结束状态。结束作用于同一群的全部会话，关闭唤醒、清空发言队列、停止正在运行的群回合、结束游戏。发送、工具、任务认领、自动唤醒和最终发言出口均检查结束状态；重新开放不会自动启用主动唤醒。

新增 GroupMemoryRulesTest 覆盖编辑保留来源、受保护记忆不能直接删除、旧快照不复活已删除记录、新参与边界及手动编辑不被自动观察覆盖。测试随 Android 构建执行，本地没有 JDK 与 Android SDK，本轮未声称 JVM 测试已经运行通过。
