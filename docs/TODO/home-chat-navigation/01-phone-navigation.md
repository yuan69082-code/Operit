# 手机页面与导航

原首页是小镇场景，手机聊天直接打开最近对话，旧抽屉和助手菜单同时承担页面导航。原侧边栏的常规入口已经可在我的访问，插件自定义入口仍依赖抽屉。

手机底部保留七项：首页、聊天、空间、工具、生活、私域、我的。首页使用主题色卡片和功能入口，空间复用已有助手空间；工具集中插件、Skill、MCP、工作流、终端和权限，保留插件的真实路由及执行回调；生活保留天气、原生闹钟和日历，提供记忆库入口；我的集中配置、历史、用量、帮助和版本。

聊天先进入好友与群列表，复用原头像、排序偏好、角色激活及建群流程，添加搜索与分组筛选。进入对话后收起底栏，返回箭头回到列表，更多菜单承载房间、关系网、群记忆、编辑及原群操作。角色按钮只在手机主窗口移除，平板及浮窗保留原切换入口。收藏和项目跳转通过真实路由打开对话，不需要重新点击好友。

私域保留，接入已有内部状态观察窗。用户的展开开关不改变助手的许可；可见内容仍由 InternalStateEngine.observation 过滤。没有自动授予私密维度访问权。

软件公共主题第一次从当前外观复制，之后独立存储。聊天内仍使用各助手或群的原主题。主题编辑分为公共外观和聊天窗口外观，公共编辑器不展示聊天气泡、输入框和角色头像等专属项。手机不再展示抽屉外观选项，平板保留。

源码接线完成。原生 Android 编译和设备显示以构建及后续实机检查为准，不能把语法检查视为实机验收。
