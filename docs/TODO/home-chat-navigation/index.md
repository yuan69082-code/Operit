# 首页与聊天导航整理

基于 2026-10-27 更新后的 main（a8927fc），保留新增的原生体验、内在状态、收藏和项目预览功能。既有已发布数据与角色隔离不变。

1. 核对侧边栏和助手菜单全部入口；手机底部整理为首页、聊天、空间、工具、生活、私域、我的，共七项。删除小镇首页，保留私域并接入内部状态观察窗，沿用助手许可过滤。补齐插件导航后移除手机抽屉。
2. 聊天先进入可搜索、排序的好友及群列表。复用原切换逻辑、头像和建群；对话隐藏底部栏、返回列表，更多菜单承载房间、关系、群记忆、编辑和群操作。
3. 软件外部页面共享独立主题，只有聊天内主题按助手/群隔离。保留完整主题编辑和旧存储，不能切换助手就更换所有页面外观。
4. 群记忆允许用户及有权限的助手编辑、保护和删除。用户确认：结束群保留历史和记忆，但禁止发言与唤醒；删记忆不删原聊天。结束与记忆删除分别处理。
5. 检查入口覆盖、切换、返回、共享主题及群状态执行边界，提交并启动 Android 构建，不等待构建结束。

侧边栏核对：原 navItems 已迁移到我的，但插件自定义入口未迁移，本次补齐。工具权限、模型、终端、聊天历史配置等仍可由原设置/工具入口到达；新的分类需保留这些路径。
