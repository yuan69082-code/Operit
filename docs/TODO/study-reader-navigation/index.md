# 阅读导航与主动心里话

用户可主动使用心里话，无需等助手开启；主授权继续可撤销所有访问。共读和写作共享目录首页、固定章导航、切章归零、滚动/分页切换，以及可跳转原版本原文的批注回复总览。保留已发布书籍与消息数据。

步骤：先补用户开启状态；将阅读容器增加可重置滚动和固定底栏；新增章节/分页策略和原文定位；补批注回复关系；提供可读的公版书籍与简单导入入口；交由现有CI检查发布。

实现：双来源开启状态（用户/AI），章目录与固定导航、UTF-16 分页、原稿定位高亮、reply_to 关系及回复工具、五本离线书包。旧数据无需迁移。

回归用例：分页重组与代理对边界、空图片章节、用户开启不被 AI 关闭、撤权清理、旧版本批注回复与错位拒绝。交由现有 Android CI 执行单元测试及编译，Windows 发布检查沿用。本地仅检查差异与书包内容完整性，未运行 Gradle。
