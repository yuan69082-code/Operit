# 来电无人应答

仓库：https://github.com/yuan69082-code/Operit

将原先一分钟超时且仅记录的来电改为两分钟超时。超时统一清理来电、铃声和通知，然后通过原会话及助手身份投递“无人应答”结果。恢复过期请求和过期通知操作使用同一处理入口，先消费请求避免重复交付。

无人应答不同于主动拒接，不更新用户交互时间、不取消无关主动任务。结果提示允许助手直接结束本轮、发送文字或调用 request_voice_call 再拨，客户端不自动重拨。

已执行 git diff --check 并核对调用路径。未运行编译、测试和手机验证。按用户要求等待第二项完成后一起提交构建。

## 聊天语音条

聊天输入区新增独立按住说话入口，沿用电话 WAV 录音和 VoiceCallAudioAnalysis 配置。松手后分析并送往录音开始时的窗口，保留输入框草稿；气泡仅显示语音条来源和原话，声学上下文供模型使用。移出按钮、切换窗口、页面销毁或进入后台会取消尚未发送的录音。最多录音六十秒，少于半秒提示重录。

补充显示与无人应答语义回归用例。当前环境无 Android SDK，本地仅完成静态差异检查，提交后交由云端 JVM 测试及双端发布流水线验证；手机手势和麦克风效果尚未实测。
