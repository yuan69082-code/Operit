# 同会话连续语音通话

## 第24版反馈：声音细节、说话者与显示

分析请求改为逐片段结构化结果，分别要求停顿位置与近似时长、语气的听觉证据、语调升降、语速变化、音色和情绪可能性。客户端额外记录低音量区间作为辅助，明确它不等同于真实停顿。无法判断时保留无法判断，疑似词保留候选；不以语义代替听觉证据。

音频分析通话开始时，用户点击按钮并独自说一句，记录本次会话的声音参考。每次请求将参考、1秒静音和当前片段合为一个同格式 WAV，并明确时间边界，参考不进入转写。较可靠匹配的片段才作为用户原话；旁人及不确定声源单独标记，只有背景声的片段不触发聊天回复。可重新确认声音，挂断删除参考文件。这是模型的暂定声源比较，不是声纹鉴权，相似声音、重叠发声及嘈杂参考仍可能误判，需要设备实测。

气泡、游标式消息和通话字幕只显示原话与通话标记；历史分析消息也通过显示适配器隐藏分析和文件路径。原始分析继续保存在聊天上下文中供模型使用，不更改数据库结构。

主动来电工具原先仅在内部分类中，未进入模型实际使用的工具提示清单。移入中英文基础分类并移除内部重复项；角色自定义工具权限继续生效，不绕过禁用配置。来电仍需要模型在一次实际运行中调用工具，不能因工具存在而保证应用无运行任务时自行拨号。

## 当前迭代：独立音频分析与 AI 来电

原有普通 STT 和直接音频模式保留。新增“音频分析通话”：每段 WAV 保存完成后由独立 DashScope 兼容接口转写并分析，再把文字及持久音频路径交给当前聊天模型，Claude 无需启用直接音频。设置入口位于电话选择面板、来电面板及语音服务设置，端点、模型、API Key、补充背景可修改；Key 不进入源码、聊天或日志，也不进入系统备份。

请求按 Omni 官方接口使用 input_audio 的 Base64 data URI、stream=true、modalities=[text]；解析 SSE 的 delta.content，仅接受完整结果。录音沿用16 kHz WAV，保存在应用外部文件目录 voice_recordings，不伪装为 m4a，也不要求新增共享目录访问权限。分析模式保留录音供聊天中的路径使用。分析失败按用户明确要求，只提交“转写失败，音频已保存”和路径；取消不提交失败消息。配置未填写时提示设置，不开启收音。

分析输出包括原话、疑似听词、声音、情绪变化、环境音、说话者。人名和同音词保留候选，不强制改写；声音性别呈现及情绪、场景推测不能当成身份事实。不保证跨片段说话者编号一致。短录音片段独立分析，不支持整通电话的声纹识别。

通话状态仍逐轮注入，但明确禁止复述；字幕和 TTS 在通用清理前过滤运行状态、mode=voice_call 和挂断控制，不删除普通正文中的下划线。

新增 request_voice_call 官方内部工具及中英文工具说明。执行链注入真实调用会话和角色，工具只请求来电；应用内弹窗与高优先级通知提供接听入口和拒接，60秒无接听自动结束，尚未接听时不录音。通知点击打开应用确认接听，支持恢复进程重建后的未过期请求。接听后沿用来电会话和角色，先通知 AI 用户已接听，再开始收音循环。系统通知被禁用时仅显示应用内来电并向工具报告这一事实。后台主动对话或定时任务运行时可调用工具；此工具本身不新增让模型定时自行唤醒的机制。

## 生命周期与交互

通话绑定启动时的聊天 ID。切换聊天、关闭对话框、离开应用或锁屏会结束通话。第一版不支持后台持续通话、主动来电或边播放边收音。说话期间提供“打断并说话”按钮，取消当前聊天生成及朗读，完成语音资源清理后重新收音。扬声器朗读时关闭收音，避免识别自己的声音。

识别、生成或朗读失败会暂停通话并显示错误，用户可重新连接。不会改用另一套识别或合成服务。错误和挂断后的清理在 NonCancellable 中完成；只释放本次创建的 STT lease 与 TTS 实例。通话期间暂停唤醒监听并在清理后恢复原有监听策略。

## 第18版设备反馈修正

通话窗口原先显示最终原始回复，导致思考与 Responses 元数据可见。改为订阅回复的公开正文流，过滤 XML 和代码块，并使用与朗读相同的清理结果显示当前句子。完整回复仍保存在原聊天中。

本轮请求附带临时通话状态，说明输入为语音转写、正文将被朗读，且无法直接听到音色或呼吸。用户消息保存语音转写标记，便于挂断后区分文字消息和通话消息。人格原文不变。

不再等待整段回复完成才开始 TTS。优先在完整句子边界送出，避免旧的50字切分截断长句。HTTP TTS 使用已有的顺序队列，在播放当前句时提前合成后续句，字幕随实际播放开始更新。其他引擎仍按自身播放接口完成一句后接下一句。收音静默阈值由3秒改为1.2秒，减少说完后的固定等待；短停顿可能较早提交，需要设备验收。

已核对通话请求回调、队列顺序、字幕正文和打断清理。没有执行本地编译或测试。需验证思考和元数据不显示也不朗读、正文未生成完时开始讲话、HTTP分句连续性、挂断后正常文字聊天，以及1.2秒停顿是否合适。
