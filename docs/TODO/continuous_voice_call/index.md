# 同会话连续语音通话

现有语音识别、TTS 和悬浮语音交互已经存在。本次在主聊天标题栏增加电话入口，复用语音服务配置与正常聊天执行链。参考 Orbis 的通话状态组织和文字会话衔接，独立实现控制器，不复制 Orbis 源码。

第一版范围：自动识别一句结束、发送、朗读并重新收音；静音、开麦、按钮打断、挂断；转写和回复由现有聊天记录持久化。识别时单独指定 3000 ms 静默时长，普通输入保持 300 ms 默认值。模型收到转写文字，不包含音色、语调和呼吸。

不修改公共人格原文、角色卡、官方工具协议、签名和更新源。没有新增常驻语气规则，没有自动摘要请求，也没有另建记忆系统。

作用域：SpeechService 及四个实现的静默参数；VoiceCallController；VoiceCallDialog；ChatScreenHeader；ChatViewModel 的通话发送与自动朗读去重；AIForegroundService 的通话唤醒暂停；中英文资源。

## 生命周期与交互

通话绑定启动时的聊天 ID。切换聊天、关闭对话框、离开应用或锁屏会结束通话。第一版不支持后台持续通话、主动来电或边播放边收音。说话期间提供“打断并说话”按钮，取消当前聊天生成及朗读，完成语音资源清理后重新收音。扬声器朗读时关闭收音，避免识别自己的声音。

识别、生成或朗读失败会暂停通话并显示错误，用户可重新连接。不会改用另一套识别或合成服务。错误和挂断后的清理在 NonCancellable 中完成；只释放本次创建的 STT lease 与 TTS 实例。通话期间暂停唤醒监听并在清理后恢复原有监听策略。
