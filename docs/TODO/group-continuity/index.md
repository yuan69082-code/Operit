# 连续群聊与群内活动

旧版群聊仅加载群窗口，发言规划可跳过成员，取消消息不能取消整个排队循环。保持已发布数据兼容，继续使用助手 ID、各自模型/记忆/能力配置。

1. 核对 ISC 子目录授权，保留原始许可和移植来源。
2. 同一助手的私聊与参与过的群记录双向连接；历史读取由代码校验归属和参与范围。默认全员一轮，结构化 @ 选择。
3. 可暂停、继续、结束的持续讨论；成员自主接话、安静、结束、安排下一次唤醒；群内活动日志。
4. 群内游戏：斗地主规则校验、狼人杀隐藏身份/夜晚/投票、情景与自定义游戏；游戏信息不得污染普通身份记忆。
5. 回归测试、构建、固定签名校验和统一发布。未经构建验证不得标记完成。
6. 主助手创建/删除其他助手、编辑角色、群成员管理；用户可拉人/踢人。关系网按固定身份保存有方向的关系、看法、进展、共同经历，主助手可全局管理。
7. 新群消息记录不可变的发言者 ID 与当时名字，请求、历史检索、主助手查看和群摘要保留来源。旧消息无法可靠判定身份时明确标注，不按同名猜测。主助手的观察不归为亲历。
