# 群内游戏

顶部游戏页开始游戏，用户和当前群成员均作为玩家。成员变动会结束本局，避免中途身份、手牌错位。牌局持久化到本群状态，恢复后可继续。

- 斗地主：三位玩家，17 张手牌加三张底牌，0–3 分叫地主，全不叫重新发牌。软件核验手牌归属、轮到谁、牌型、压制关系、两次不出后的领出权和胜负。支持单、对、三张带牌、顺子、连对、飞机、四带二、炸弹和王炸。
- 狼人杀：4–12 位玩家，简化规则为狼人、预言家、守卫和村民。夜间行动、公开讨论、投票顺序推进；每人每阶段提交一次。夜间袭击平票不杀人，投票平票不出局。守卫可保护自己，可连续保护同一人；预言家结果私有，死亡不公开身份，结束后揭示。
- 情景与自制游戏：保存规则模板，按座位依次提交公开或私密行动。AI 可编写并收藏规则。此入口是规则与剧情玩法，不执行生成的任意程序，也不承诺对任意自制规则自动作裁判。

手牌、身份和私密结果仅进入对应玩家的私有请求上下文。工具结果只返回公开局面；游戏回复在移除思考和私密行动参数后显示、保存。软件在后台完成工具执行，界面等待公开回复。模型主动在公开发言中披露的信息属于公开发言，因此不保证模型绝不失误或说漏嘴。

群摘要可以压缩已公开的游戏聊天，当前局面由结构化游戏状态保存，不依赖模型从长历史还原。游戏期不做自动长期记忆写入；恢复日常后提示游戏身份已结束，保留一起游戏这一经历，但不改变日常身份。

仅移植 roundtable 的 ISC 子目录 `server/lib/visibility.js`，原始文件、完整许可与修改说明在应用资源中，关于页可查许可来源。未复制未声明统一许可的仓库外层代码。
