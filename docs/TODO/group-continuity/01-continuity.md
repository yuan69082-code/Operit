# 群聊连续性与发言归属

群聊使用原助手 ID，调用对应的模型、记忆空间和能力配置。每位成员可关联自己的一个私聊，默认连接最近使用的私聊。请求中只附最近六条的有限预览，更多原文通过 `group_chat history` 分页读取，不重复塞入整份历史。

群内公开消息记录到当前成员的参与快照。回到私聊时附最近两个已参与群的预览，聊天顶部可打开参与过的群记录。离群后快照冻结，历史工具只允许读取已参与时间范围；其他助手的私聊不向普通成员开放。

新群消息在独立存储中绑定生成者 ID 和当时名称。请求组装使用身份比较结果，重名与改名不会改变归属。旧消息没有可证明的 ID 时标为未知，不凭同名补认领。群摘要按姓名与 ID 逐人署名，私聊摘要仍保持自身第一人称。

主助手查询输出带记录所有者、查看者、时间、群与聊天来源。读取他人记录属于观察；主助手权限不转移经历归属。群上下文不展开其他成员查阅私聊、管理记录和关系网的工具结果。

新的参与快照、关系网、发言者映射保存在应用私有 SharedPreferences，不重写现有消息表。覆盖更新保留；单独导出旧格式聊天文件不包含这些附加数据。

默认一条用户消息让当前成员各答一轮。`@` 按 ID 单选、多选；没有指定为全员。顶部按钮或输入 `@` 打开选择器，重名时应结合成员设定区分。
