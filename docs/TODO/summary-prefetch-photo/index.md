# 提前整理上下文与手机图片工具

现状：压缩需串行生成和审阅整段原文；失败重试重复生成草稿。手机已有读图能力，缺少相册目录和独立拍照工具。

范围：保留 AI 第一人称与审阅后提交规则，提前整理稳定的历史批次，按来源和模型配置复用草稿、已审阅摘要，记录阶段耗时。原始聊天不删除，后台准备不锁输入框。

图片：新增拍照、相册分页、读取和发送图片的工具，遵循 Android 相机与相册授权，拍照显示可见预览；结果保存在本机并通过现有图片消息通道显示。
