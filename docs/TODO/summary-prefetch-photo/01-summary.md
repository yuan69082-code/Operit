# 上下文整理

按完整对话轮次分批，目标每批约 8000 字符；超长单轮保留完整原文。每批基于上一份已审阅摘要生成并审阅，复用没有变化的来源与配置。仅提前准备完整批次，最近两轮留给正常聊天。

提前准备从压缩阈值的七成开始，成功结果进入本进程有界缓存；不修改聊天、不显示占用输入框的压缩状态。正式压缩仍核对原文，任何未获批准的结果不得写入聊天。

记录草稿、审阅的输入字符数、缓存命中与耗时，不记录原文或密钥。界面显示批次与当前步骤。

摘要生成及审阅共用忠实性要求：不从亲昵称呼、关系约定或角色卡推定角色扮演；只有原文明确要求的创作内容才使用相应描述。移除模板中无条件提示剧本、虚构信息的示例。旧摘要不是这类定性的原始证据，明确纠正优先；不把一方要求写成双方已达成约定。保留第一人称及用户自定义栏目接口。

不批量替换用户已有摘要中的词语；旧记录可在原有编辑入口纠正，后续生成及审阅按新增约束核对。模型输出具有不确定性，提示词与规则接线测试不能替代真实模型语义验证。
