# 聊天资料携带与请求失败修复

## 目标与依据

本批基于主分支 `c4b066d`，对应已有 `+157`；用户日志中的已安装版本为 `+156`。
该版本已包含前一批回复流异常处理。新的崩溃记录仍显示 Gemini HTTP 400
`Thinking level is unsupported: THINKING_LEVEL_MINIMAL`；另一张截图显示 HTTP 402
预付额度耗尽。日志为重启后的日志及最后一次崩溃堆栈，未保存导致失败的模型与完整请求。

用户同时要求减少旧工具资料在后续每轮全文携带，并修正人格、关系、偏好先轮换取一页再匹配的选材顺序。

## 实施范围

1. 在请求准备阶段节选已完成、可精确回查的成功工具返回，保存的聊天原文不变。
   当前工具续轮、错误、未完成消息及无回查权限的资料保持完整。
2. 从当前助手全部已采用条目中查找与当前输入相关的内容，再进入已有页数与统一预算。
   轮换作为补充；归档索引按数据变化刷新，不额外调用模型。
3. 核查原生 Gemini 回复的异常传递路径，补充覆盖初次回复与工具续轮的原生流回归用例。
4. 补齐旧内置思考配置被重新格式化后未迁移的情况；自定义参数与规则顺序不改。
   HTTP 400 档位错误和 HTTP 402 余额错误显示可操作的说明，并保留服务原始错误。

不改变已采用人格、关系、偏好的原文、候选采用规则、记忆内容、账户计费或上下文上限。

## 代码外的依据

Google 官方文档列出 Argon、3.7/3.8 Flash 等型号不支持 `MINIMAL`，设置后会返回 400：
https://firebase.google.com/docs/ai-logic/thinking

本次日志没有原始请求与型号，不能据此断定用户实际选择了哪一个型号或是否使用自定义规则。
迁移只修复与旧内置 JSON 结构完全相同的配置，保留数组优先级和所有真实自定义值；合法 HIGH 等选择保留。
402 提示来自服务器预付余额错误，软件修订不改变账户余额。
