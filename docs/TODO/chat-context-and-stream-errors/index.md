# 聊天资料携带与请求失败修复

## 目标与依据

本批基于主分支 `c4b066d`，对应已有 `+157`；用户日志中的已安装版本为 `+156`。
该版本已包含前一批回复流异常处理。新的崩溃记录仍显示 Gemini HTTP 400
`Thinking level is unsupported: THINKING_LEVEL_MINIMAL`；另一张截图显示 HTTP 402
预付额度耗尽。日志为重启后的日志及最后一次崩溃堆栈，未保存导致失败的模型与完整请求。

用户同时要求减少旧工具资料在后续每轮全文携带，并修正人格、关系、偏好先轮换取一页再匹配的选材顺序。

## 实施范围

1. 在请求准备阶段节选已完成、可精确回查的成功工具返回，保存的聊天原文不变。
   当前工具续轮、错误、未完成消息及无回查权限的资料保持完整。
2. 从当前助手全部已采用条目中查找与当前输入相关的内容，再进入已有页数与统一预算。
   轮换作为补充；归档索引按数据变化刷新，不额外调用模型。
3. 核查原生 Gemini 回复的异常传递路径，补充覆盖初次回复与工具续轮的原生流回归用例。
4. 补齐旧内置思考配置被重新格式化后未迁移的情况；自定义参数与规则顺序不改。
   HTTP 400 档位错误和 HTTP 402 余额错误显示可操作的说明，并保留服务原始错误。

不改变已采用人格、关系、偏好的原文、候选采用规则、记忆内容、账户计费或上下文上限。

## 验证与交付

新增有针对性的回归用例，并进行差异和调用链审阅；`git diff --check` 通过。
用户已明确授权运行针对性测试并推送修复分支；使用现有 Android Tests 环境执行定向 JVM 回归。
本批不触发自动合并发布。

前两项及旧配置迁移已经完成代码修改。筛选属于本地字词检索，使用当前输入；没有增加语义模型调用，不能声称实现了语义唤起。
相关性顺序还须穿过统一预算：最佳匹配的人格及关系/偏好正文或片段，先于轮换目录得到预算机会，
后续轮换不重复加入相同来源。用于传递优先级的临时 ID 在预算处理时移除，不作为模型输入。
历史工具节选仅适用于可通过现有 `group_chat history_message` 工具读取原文的已完成私聊消息；
群聊、禁止工具、没有完成时间的旧导入记录和仍在进行的工具链保留原文。超过 4096 字符的成功结果保留首 768 与尾 256 字符及回查位置。

崩溃尚未确诊并验证修复。已发布的 Shared `+156` 源码包含共享流、生产子协程和主订阅的错误边界；
`+157` 相对它没有修改这些边界。单凭手机版本后缀不能验证实际 APK 的源码提交，
因为不同工作流的运行编号可能相同。两次独立调用链审阅没有发现可以据此确认的遗漏点，
因此没有再添加全局吞错、重试或未经证实的处理分支。

原有 HTTP 400 测试绕过了 `EnhancedAIService`。本批让 `EnhancedReportIsolationTest` 的 fixture
使用原生修订事件流及真实 TokenTrackingAIService，并新增真实 Gemini 序列化加模拟 HTTP 响应的测试，覆盖 400、402、
首次请求、工具续轮、工具不重做、失败状态不采用和下一轮可继续。该用例尚未执行，不能把新增源码当成测试通过。

本分支暂时通过 Android Tests 的分支限定触发执行定向回归；普通工作流仍保留完整测试命令。
验证结束后移除这条临时分支触发，并记录实际结果。

## 代码外的依据

Google 官方文档列出 Argon、3.7/3.8 Flash 等型号不支持 `MINIMAL`，设置后会返回 400：
https://firebase.google.com/docs/ai-logic/thinking

本次日志没有原始请求与型号，不能据此断定用户实际选择了哪一个型号或是否使用自定义规则。
迁移只修复与旧内置 JSON 结构完全相同的配置，保留数组优先级和所有真实自定义值；合法 HIGH 等选择保留。
402 提示来自服务器预付余额错误，软件修订不改变账户余额。
