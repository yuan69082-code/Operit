## 配置兼容与错误边界

档位依据 [Google 的模型思考能力表](https://firebase.google.com/docs/ai-logic/thinking)，核对日期 2026-11-10。Gemini 3 Pro 为 LOW/HIGH；3.1 Pro、3.7/3.8 Flash 与 4 Argon 不支持 MINIMAL；3.1 Flash Image 为 MINIMAL/HIGH。只对已确认型号增加高优先级规则，其他既有规则及用户自定义契约保留。

模型配置版本 5 → 6 只迁移未修改的旧内置规则：被错误设置为 MINIMAL 且新规则最低可用档位为 LOW 的配置改为 LOW，合法档位保持原值。自定义规则不被覆盖；请求本身不在 400 后换档重试。旧 v4 Vertex 预算/档位修复仍按原顺序执行。聊天、助手状态和历史不迁移、不清空。

共享生产协程增加结构化边界，等待其子协程及完成回调结束后才发布最终成功或失败。完成回调和生产子协程错误均成为主订阅可读取的失败，旁观文本订阅不会因此成为未捕获异常。直接 HTTP 400 保留失败，不按正常回复完成，也不进入网络重试。

该补丁补齐可由回归用例验证的生产子协程与清理异常缺口；手机日志没有保留失败请求模型 ID，也没有完整的协程父链，尚不能证明这两个缺口就是该手机现场的唯一异常逃逸点。
