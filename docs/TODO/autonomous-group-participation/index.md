# 群成员自主参与

原行为：@ 筛选回应者，respond 指定下一位接话，wait_user/end 清空全群队列。某位助手不交棒时，其他成员无法自行回应。

目标：@ 仅表达称呼对象并调整首次判断顺序。所有成员自行决定潜水或公开发言；新公开消息让其他成员重新判断。助手也能在群中通过 whisper 单独联系用户。

## 作用域与实施

- 调度沿用串行执行，确保后续成员看到已保存的最新发言。每位成员获得判断机会不代表必须发言
- 公开新消息将其他成员加入判断队列，已等待的成员排在前面。没有公开消息时不增加队列，所有成员安静后停止。用户的暂停、结束、次数与时间上限继续有效
- quiet、wait_user、end 只表达本人的决定。respond 及旧控制标记仍接受，但不再作为发言许可；旧 continuous 值不再限制日常接话
- 群内游戏仍使用现有行动队列、身份可见性和禁言规则
- whisper 只把调用助手主动填写的 text 发给用户，不复制群记录或其他私聊。目的地由 #6 的 AssistantWindowRouter 解析为该助手最近活跃的私聊，归属不匹配或尚无私聊时明确报错
- 私聊通过现有历史委托保存并通知用户，不切换用户当前页面。群活动记录只显示已发送，不含私聊正文或目的地
- 工具调用及私人结果继续过滤，取消公开占位文字；两种聊天样式隐藏已存旧消息中的两个精确占位文本，不改原数据库
