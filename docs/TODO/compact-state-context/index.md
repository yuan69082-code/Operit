# 每轮状态上下文去重

仅整理请求表示，不改状态演化、数据或候选评分。状态请求副本省略 triggers、maxDelta、halfLifeHours；当前值、持续性、影响规则、权限、变化和候选原因完整保留。完整定义继续通过内部状态工具读取。

开启内部状态时，念头只在其 JSON 中发送一次，并保留操作说明。外部三项待办提醒仅省略内部32项候选已覆盖的ID，不在候选内的提醒继续发送。关闭内部状态时维持独立提醒。

真实发送记录状态JSON整理前后字符数与条目数，不记录私密正文，也不将字符数冒充token。该统计不包含全部提示词、媒体或服务商封装。

新增测试验证请求投影保留状态意义、评分、变化和完整念头，且不修改原始定义。Android编译及JVM测试由PR流水线验证。
