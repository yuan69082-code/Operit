# 聊天表情包

现有表情库按 AI 角色保存，只有特定聊天模式注入随机情绪标签规则，没有用户发送入口或 AI 收藏工具。

保留已发布的角色表情库及原有标签协议。增加独立的用户表情库、聊天选择和收藏入口，以及绑定执行角色的 AI 表情工具。原图保存，发送时保留独立副本，删除收藏不破坏历史消息。

范围与步骤见 [01-implementation.md](01-implementation.md)。沿用原 APK 包名和固定签名，通过现有移动发布流程交付。

已发布 [1.12.2+51](https://github.com/yuan69082-code/Operit/releases/tag/v1.12.2%2B51)，自动检查与签名结果见 [验证记录](validation.md)。
