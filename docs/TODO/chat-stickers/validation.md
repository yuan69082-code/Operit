# 验证记录

自动检查覆盖：用户与 AI/群组的存储隔离、旧表情元数据兼容、分类路径与标记校验、动画原字节保留、重复发送复用副本、删除收藏后历史副本保留、超限导入清理、分页错误，以及执行身份不能由模型伪造。

设备验收路径：

1. 聊天加号打开表情包，选内置图片、添加到消息、发送。纯表情和文字加表情都应正常显示；切换气泡与普通布局再检查。
2. 导入 GIF 与 WebP，并分别点开预览；关闭再启动软件，收藏仍在。重复导入同图不增加条目。
3. 点开聊天里的 AI 图片，按爱心收藏，再到“我的”发送。删除收藏后，已发送的消息仍能打开图片。
4. 开启 AI 表情开关，让 AI 收藏一张聊天图片并再次发送。其收藏出现在对应身份的“AI 的收藏”中；不同身份的表情库不混用。群聊面板可选择成员。
5. 关闭 AI 开关，工具调用应返回关闭状态，用户仍能发表情。启用工具且模型有看图能力时，用户表情会作为图片输入；不支持直接看图的模型可按需调用 stickers view 与已配置的识图服务。

自动检查不能替代设备上的弹窗、授权、动图播放和模型自主调用验证。当前环境没有连接可运行此 APK 的手机，未声称通过这些设备检查。
