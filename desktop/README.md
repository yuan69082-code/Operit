# Operit Windows 共享聊天预览

Windows便携包解压后双击desktop/Start-Operit.cmd。包内包含Node运行时，不要求单独安装Node。启动窗口需要保持打开，浏览器窗口承载复用的WebChat界面；本阶段不是原生桌面安装器。

首次打开电脑服务设置，填写完整OpenAI兼容chat/completions接口地址、API Key、模型名、原有角色名称及系统提示词。此阶段不自动读取手机版的密钥和角色配置，不新建一套替代主体的提示词。开启电脑工具后，可使用当前Windows用户权限下的截图、鼠标点击、SendKeys、PowerShell和文件工具。视觉模型才能理解截图；未启用视觉的接口会明确报错。尚未实现通话、摄像头、UIA控件树或长期记忆折叠。

会话与配置保存在LOCALAPPDATA/Operit/shared-data，独立于解压目录。后续更新程序包保持这个目录。首次启动生成服务Token，电脑设置页显示可供手机连接的局域网地址。手机必须能访问此电脑，首次使用可能需允许Windows防火墙的局域网入站连接。远程互联网访问和VPS部署不在此预览包里自动配置。

手机版设置 → 数据和权限 → 外部HTTP调用 → 共享聊天可打开同一服务。共享入口使用同一会话记录，手机原生本地聊天仍保留自己的本地存储；不是所有原生界面已经变成云端同步。服务设置页可显式导入手机HTTP接口提供的文字记录，重复导入同一会话不会再次新增，原有记录不被删除。历史附件和角色配置需要后续迁移。

两端共享界面定时刷新当前会话。一个会话同时只生成一个回复，另一端同时发送会收到忙碌提示；不同会话独立。中断发送连接会取消模型请求，正在执行的Windows命令可能持续到其30秒超时或正常结束。

统一预览工作流按同一提交构建Windows包和Android包，所有必需构建成功后才生成共享更新清单；更新页提供该批两个产物。现有手机版main的个人更新通道不发布开发分支包。预览尚不执行自动后台替换或自动安装。

开发运行：使用Node22，先按web-chat已有流程准备网页构建产物，再运行desktop/src/launcher.cjs。单元和HTTP集成检查由共享预览工作流执行。AGENTS约定未主动在本地运行编译或测试命令。
